Android will not let an app bind a port below 1024, so port 80 is out of reach — 8080 is the default, with 8000 and 8888 as fallbacks. The password is set in the app on the phone and can only be changed there.

The panel sets the pace, not the phone, and which frame encoding is fastest differs wildly between panel generations — a 96×16 E15 is eight times quicker over the live 0x0000 path, while a 144×16 on firmware 21.17 is eight times quicker over legacy PNG. So the app measures each candidate once per panel size and remembers the winner instead of guessing. The knobs can still be pinned by hand in shared_prefs/ipixel_lab.xml.
